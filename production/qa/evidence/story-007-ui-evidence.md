## Start-to-rematch loop with 2+ PCs

- `part1/e2e_host.log`, `part1/e2e_client.log`: a host and a client running as separate processes, driven through the real screens. The run goes menu, host, the client joins, the client picks racer 3 on the bike and gets ready, the host starts, then race, results, Rematch, a second race and its results. The client's pick reaches the host step by step; both PCs show the same roster and the same results. 0 ERROR on both.
- `part3/e2e/`: a third PC joins 12 s into the race. It is not kicked: it watches, sees the results, and races the rematch. 0 ERROR on all 3.

## Sound

- 23 synthesised wavs in `assets/audio/`, regenerated byte-identical by `tools/synth_audio.py`. Each file's length, peak and frequency is in `audio/README.md`.
- `tools/audio_check.gd` passes headless and windowed.
- The engine, drift and music loops are set at import and loop over their full length (1 s, 1 s, 24 s). The loop-end bug under QOA compression was found and fixed by the coordinator.
- Mute: the M key or controller Back, plus a Sound button in the main and pause menus. The setting is saved in `user://audio.cfg`.
- Not verified: nobody has listened to the sounds yet.

## Controls menu

- `part3/controls_check.log`: 24 checks pass. They cover rebind, keyboard and controller swap, save, reload, reset, a missing file, and a corrupt file falling back to the defaults.
- `part3/controls_capture_check.log`: 14 checks pass. They cover Enter and Esc in capture, trigger threshold and swap, all with simulated input.
- Not verified: rebinding with a real keyboard and controller.

## Version check (found during verification, fixed with the owner's approval on 2026-11-21)

`part3/version-handshake/`:

| Case | Result |
|---|---|
| Same build | 0 ERROR |
| Different version | Refused before any RPC: "The host runs a different version of the game (host v99, you v8). Update to the same build."; 0 ERROR on both PCs |
| Old build (v3) joining | Dropped after 3 s and never listed; the host logs 7 engine lines (`scene_multiplayer.cpp:97`) and 0 from game code |
| Spectator | 0 ERROR on all 3 PCs |

Before this fix, an old build was accepted into the race and logged 1,378 errors (`part3/old-build-refusal/`).

## Regressions and frame rate

- Automated races after each part: 0 ERROR and 0 WARNING. Checked with `tools/bot_race_test.sh`, and with `tools/item_net_test.sh`, where hits are identical on all 3 PCs.
- Windowed host with 11 bots, sound playing, no screenshots (`part2/fps_castle_windowed`): fps min 59, p5 60, median 60.
